# NIKKE 데이터 아카이브

공개 [니케 과금 패키지 효율표](https://docs.google.com/spreadsheets/d/1qUSwYnpDtWAD_aq_4L6dC6py2vM19WtLed2AGKSdIPk/edit?usp=sharing)의 **2026-11-02 스냅샷**을 GitHub Pages에서 독립적으로 볼 수 있게 만든 비공식 자료실입니다. Google Sheets 접속 없이 19개 공개 탭의 상품·쿠폰·일정 데이터를 검색하고 정렬하며, 재화 가치와 선택을 바꿔 효율을 다시 계산할 수 있습니다.

## 범위와 기준

- 원본 공개 탭 19개, 데이터가 있는 행 2,124개, 원본 셀 21,041개를 확인했습니다. 원본 작성자의 설명 셀 19개는 재게시하지 않았습니다.
- `패키지효율` 탭의 원본 접힌 행 273개도 포함합니다. 체크박스로 숨겨 볼 수 있습니다.
- 원본에 숨겨진 과거 탭 57개는 공개 탐색 화면에 나타내지 않습니다. 계산이 참조하는 과거 커스텀 탭 3개만 내부 계산 데이터로 포함했습니다.
- 상품·이벤트·CD-Keys는 현재 판매·진행·사용 가능 상태를 뜻하지 않습니다. 스냅샷 자동 갱신은 없습니다.
- 숫자 형식(₩, %, 소수 자리), 드롭다운 선택지, 조건부 서식(추천·가성비·미선택·달성)과 이벤트 일정의 병합 기간은 원본 XLSX의 정의를 옮겨 표시합니다.
- 원본의 ‘효율’은 재화가치기준 탭의 가중치를 따릅니다. 별도 표시한 픽업 환산 횟수는 `쥬얼 / 300 + 고급 모집권`이며 일반 모집권을 더하지 않습니다.
- 입력한 가치, 수량, 선택은 해당 브라우저의 `localStorage`에만 보관됩니다. 입력 때문에 수식이 오류를 내면 `#DIV/0!`, `#N/A`처럼 오류를 표시하고 스냅샷 값을 대신 보여 주지 않습니다.

## 원본 수식 보정

원본 수식을 그대로 계산하되 아래 8칸만 보정합니다. 원본 기본값에서는 보정 전후 결과가 같고, 화면의 해당 칸에 ‘보정’을 표시합니다. 보정 목록과 이유는 `corrections.mjs`에 있습니다.

| 칸 | 원본 수식 | 보정 | 이유 |
| --- | --- | --- | --- |
| 커스텀 D13, D14, D22 | `VLOOKUP(C13,B52:D57,3,FALSE)` | `VLOOKUP(C13,B51:D57,3,FALSE)` | 조회 범위가 드롭다운 목록의 첫 선택지를 빠뜨려 그 선택지를 고르면 `#N/A` |
| 스텝업 H7~H10 | `IF(B7=TRUE,H6*F6/F7+G7*E7/F7,H6)` | `…+G7*E7*C7/F7…` | 누적효율이 반복구매 수량을 반영하지 않아 누적가격과 어긋남 |
| 스텝업 J9 | `('재화가치기준'!D7*2400+…)` | `('재화가치기준'!D6*2400+…)` | STEP 11 무료쥬얼을 유료쥬얼 가치로 계산함. 같은 상품의 다른 5개 탭은 D6 사용 |

## 확인

```sh
node test-snapshot.mjs
```

공유 수식을 포함한 숫자 수식 7,988개와 텍스트 수식 21개를 원본 캐시 값과 대조하고, 재화 가치 수정 후 재계산, 오류 전파, 보정 수식, 픽업 환산, 숫자 형식, 드롭다운 698칸, 조건부 서식, 일정 1,879건을 확인합니다.

`snapshot/`에는 공개 데이터의 값, 계산식과 표시용 메타데이터만 담고 원본 XLSX, 로그인 정보 및 연락처는 포함하지 않습니다. 각 탭 JSON의 셀은 `[주소, 값, 수식, 타입, 형식 번호]`이며 `formats`, `inputs`, `rules`, `timeline`은 원본 XLSX의 숫자 형식, 데이터 확인, 조건부 서식, 일정 병합 칸에서 추출했습니다.

로컬 미리보기는 `node preview-server.mjs` 실행 후 http://127.0.0.1:4187 에서 볼 수 있습니다.
