# 니케 4주년 과금 효율표

2026-11-02에 확인한 [공개 효율표](https://docs.google.com/spreadsheets/d/1qUSwYnpDtWAD_aq_4L6dC6py2vM19WtLed2AGKSdIPk/edit?gid=1190480704#gid=1190480704)의 상품 정보로 만든 독립적인 정적 비교 페이지입니다. 실시간 연동은 하지 않습니다.

픽업 모집 환산 횟수는 `고급 모집권 + 쥬얼 / 300`입니다. 일반 모집권과 성장 재료는 환산 횟수에 포함하지 않습니다. 30일 보급품과 출석·캠페인 상품은 수령 조건을 충족했을 때의 수량입니다.

## 로컬 확인

```sh
node --test test.mjs
```

`index.html`을 정적 서버로 열면 됩니다. 빌드나 외부 의존성은 없습니다.

## GitHub Pages 게시

저장소의 `main` 브랜치 루트를 GitHub Pages 게시 소스로 선택하면 됩니다. 상대 경로만 사용하므로 프로젝트 Pages URL에서도 실행됩니다. 공개 페이지로 게시하기 전에는 저장소의 공개 범위를 확인하세요.
